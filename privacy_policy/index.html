MultiPost Desktop

Privacy Policy · Last updated: 28 August 2026

This Privacy Policy applies to the MultiPost Desktop Windows application and this official website. MultiPost Desktop is a local-first Windows desktop application that helps its user prepare and publish selected videos to connected social-media accounts.

Data stored on your computer

MultiPost Desktop stores account connection tokens, encrypted application credentials, captions, drafts, publishing history, settings, generated cover frames, and platform-ready video copies in your Windows user profile under %APPDATA%\MultiPost. MultiPost Desktop does not operate a central database or cloud account service.

Connected social networks

When you connect a platform, MultiPost Desktop opens that platform's official authorization page. The platform returns access and, where applicable, refresh tokens that let MultiPost Desktop perform only the actions you approve. The application uses these tokens to identify the connected account, prepare publishing requests, upload media selected by you, check processing status, and publish or schedule content at your direction.

Depending on the platforms you connect, data is transmitted to Meta services (Facebook, Instagram, and Threads), TikTok, Google/YouTube, LinkedIn, X, and Pinterest under their respective privacy policies and terms.

TikTok

When you click Log in, MultiPost Desktop opens the official TikTok sign-in page. After you approve, TikTok returns access tokens so the app can publish videos you choose. We request user.info.basic, video.upload, and video.publish. We do not read your TikTok followers, messages, or For You feed.

Videos and temporary hosting

Your original videos remain on your computer. When you publish, MultiPost Desktop sends a platform-optimized copy to each network you selected.

Instagram or Threads may require Meta's servers to fetch the video from a public HTTPS address. If direct upload is unavailable, MultiPost Desktop uploads a temporary public copy to the MultiPost Desktop GitHub Pages media location. That copy can be accessed by anyone who knows its URL and may remain in GitHub history. Do not use this fallback for confidential media.

Optional AI caption rewriting

If you configure an external AI API key and request an AI rewrite, the title, caption, call to action, platform name, and related prompt text are sent to the AI provider and are handled under that provider's policy. If no external key is configured, MultiPost Desktop uses its local caption optimizer.

Sharing and sale of data

MultiPost Desktop does not sell personal data and does not use it for advertising. Data is shared only with the services required for the action you request, such as authentication, media hosting, AI rewriting, and publishing to the selected network.

Retention and deletion

You can disconnect a platform from the MultiPost Desktop Platforms dashboards screen to remove the locally stored access and refresh tokens for that platform. You may also revoke MultiPost Desktop from the connected platform's Apps and Websites or business-integration settings.

To delete all local MultiPost Desktop data, close the application and remove the %APPDATA%\MultiPost folder. This removes local tokens, drafts, settings, history, generated covers, and prepared media. Content already published to a social network must be deleted from that network.

Security

MultiPost Desktop encrypts sensitive locally stored values using Windows-provided protection tied to the Windows user account. No method of storage or transmission is guaranteed to be completely secure.

Children

MultiPost Desktop is not directed to children under 13 and does not knowingly collect children's personal information.

Changes to this policy

This policy may be updated when MultiPost Desktop's features or connected services change. The latest version and effective date will remain available on this page.
