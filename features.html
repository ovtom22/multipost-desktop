MultiPost Desktop

Features of the MultiPost Desktop Windows application.

TikTok publishing

MultiPost Desktop uses TikTok Login Kit and the Content Posting API. You approve user.info.basic, video.upload, and video.publish. The app uploads the video you picked and the caption you reviewed. It does not read your For You feed, followers, or messages.

Other networks

The same video can also go to YouTube, Instagram, Facebook Page, Threads, X, LinkedIn, and Pinterest. Each destination uses that network’s official login. You can turn any destination off before you post.

Review tools

  • One master title and description, then a per-network caption
  • Optional AI rewrite that keeps YouTube chapter timestamps only on YouTube
  • Cover frame picker for networks that need a still image
  • Optional subtitle file (.srt / .vtt) for YouTube and Facebook Pages
  • Queue, history, and a local scheduler while MultiPost Desktop is running

What MultiPost Desktop does not do

It does not scrape any network. It does not post from a cloud server while your PC is off. It does not sell data or show ads. Tokens stay in your Windows profile under %APPDATA%\MultiPost.
