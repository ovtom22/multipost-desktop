WINDOWS PACKAGE AVAILABILITY

MultiPost for TikTok Sandbox review.

A separate portable Windows x64 candidate is prepared for review. It uses TikTok Sandbox access and its own local profile. Reviewers can request a free copy through TIGO support. Delivery and permitted Sandbox account access must be confirmed before a reviewer can use it.

PORTABLE BUILD 0.1.0-review.20261026.3

What the review package includes

  • ✓TikTok-only connection through the HTTPS authorization service, with the developer secret held on the server.
  • ✓A local video preview, editable caption, current creator information and account-specific duration limit.
  • ✓Manual audience selection, optional interaction and disclosure controls, and consent before upload.
  • ✓Bundled Python runtime, FFmpeg and FFprobe. No administrator installation or separate Python installation is required.
  • ✓A separate review-data profile that does not import personal MultiPost accounts, drafts or history.

OPEN THE COMPLETE PACKAGE

When an approved copy is supplied, extract the entire ZIP and keep the _internal folder beside MultiPost.exe. Verify the supplied SHA-256 before opening it. The portable candidate is separate from a signed customer installer.

SANDBOX ACCOUNT ACCESS

Use a permitted test creator.

The package connects to the MultiPost TikTok Sandbox. A public TikTok account is not automatically allowed. Unaudited posting requires a private creator account and the manually selected Only you audience. The audience dropdown does not change account privacy.

Review-profile storage and deletion are explained in the Privacy Notice.
