MultiPost Desktop

Install the official MultiPost Desktop Windows application.

Windows installer

MultiPost Desktop is a Windows 10 / 11 desktop app. The current installer is distributed by the developer after a build. After install, open MultiPost Desktop, go to Accounts, and click Log in with TikTok.

The installer is per-user. Your logins stay in %APPDATA%\MultiPost if you upgrade or reinstall.

System requirements

  • Windows 10 or Windows 11
  • A web browser for official network sign-in
  • A video file on disk
  • Your own TikTok account, plus any other accounts you choose to connect

After install

Read How it works for the first publish, and Support if sign-in or a scheduled post fails.
