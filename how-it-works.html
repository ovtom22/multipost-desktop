TIKTOK CONTENT POSTING FLOW

A creator reviews the post before the video leaves the computer.

The Windows review candidate lets creators prepare their own local video, inspect the destination account and settings, and explicitly approve the upload. The current package uses TikTok Sandbox access.

  1. Connect a permitted creator account

    Open TikTok's official sign-in page using an account allowed by the MultiPost Sandbox target-user configuration. Sign-in returns through TIGO's HTTPS authorization service; the developer secret stays on that server. The desktop then requests current creator information directly from TikTok.

  2. Select original or rights-cleared content

    The creator chooses a video from the local computer and reviews it before upload. The available duration and media restrictions are checked against the current TikTok account settings.

  3. Choose the audience and disclosures explicitly

    The review shows the creator identity and the privacy choices returned by TikTok, with no audience preselected. Comment, Duet and Stitch begin unchecked; controls are unavailable when TikTok does not allow them. Commercial disclosure is off by default and requires a truthful brand choice when enabled. Select the AI-content label when applicable.

  4. Confirm the reviewed post

    Before transfer, the creator reviews the selected account, video, caption, audience, settings, and platform terms, then gives explicit posting consent. Changing material details requires a fresh review.

  5. Check the saved receipt before trying again

    The Direct Post flow retains TikTok's receipt so Activity can check processing without creating another upload. Processing, an uncertain result and a confirmed outcome remain separate states. Two creator-approved Only you tests completed on 28 and 29 October 2026, with saved receipts and private posted results verified. An upload or completion message does not guarantee public visibility.

REQUESTED TIKTOK ACCESS

Creator identity and Direct Post

The app requests user.info.basic to identify the connected creator and video.publish for the reviewed Direct Post. FILE_UPLOAD is the file-transfer method within Direct Post. This version does not implement the separate inbox flow associated with video.upload.

TikTok Support confirmed that video.upload is included automatically with Content Posting API and cannot currently be removed manually. MultiPost records the actual grant returned by TikTok. The included permission will be disclosed to reviewers together with the fact that this build does not use it.

NOT PART OF THIS FLOW

No feed, follower, or message reading

The flow does not request the creator's For You feed, follower list, direct messages, or other users' content. Current-account information keeps the publishing decision visible to the creator.

WHAT MULTIPOST DOES

Maintains a review boundary

The app preserves an explicit review and consent step between local media preparation and the TikTok publishing action.

WHAT MULTIPOST DOES NOT CLAIM

It cannot override TikTok

TikTok controls account eligibility, moderation, visibility, processing time, and production approval. The application does not guarantee that a post will be public or receive distribution.

UNAUDITED POSTING LIMITS

A private creator and an Only you post.

TikTok requires both a private creator account at posting time and Only you visibility for unaudited clients. Choosing the audience in MultiPost does not change the TikTok account's privacy. Private tests completed on 28 and 29 October 2026. TikTok production approval remains pending. Read TikTok's Content Sharing Guidelines.
