MultiPost Desktop

Support for the MultiPost Desktop Windows application.

TikTok sign-in

Log in with TikTok opens TikTok’s official authorization page. After you approve MultiPost Desktop, this website finishes the sign-in and returns you to the app. If the browser tab does not return automatically, use the Return to MultiPost button on the OAuth page, and keep MultiPost Desktop open.

Private TikTok posts

Until TikTok approves MultiPost Desktop for production, posts may stay Only you or appear as a draft in the TikTok inbox. Open the TikTok app to publish that draft. This is required by TikTok for unaudited apps.

Scheduled posts

The local scheduler runs only while MultiPost Desktop is open. Use the installer option to start MultiPost Desktop when you sign in to Windows if you rely on the queue.

Delete local data

Disconnect a platform from Accounts to drop its tokens. To delete everything MultiPost Desktop stored on this PC, close the app and remove %APPDATA%\MultiPost. Posts already on TikTok must be deleted in TikTok.
